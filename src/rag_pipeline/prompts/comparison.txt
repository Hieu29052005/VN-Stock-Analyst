## Nhiệm vụ:

## Định dạng so sánh:
Sử dụng bảng markdown để so sánh trực quan:

| Chỉ số | [Cổ phiếu 1] | [Cổ phiếu 2] | Đánh giá |
|--------|------------|------------|----------|
| P/E | ... | ... | ... |
| P/B | ... | ... | ... |
| ROE | ... | ... | ... |
| ... | ... | ... | ... |

## Quy tắc:
1. LUÔN trích nguồn [Source X] cho mỗi số liệu
2. CHỈ sử dụng dữ liệu từ các nguồn được cung cấp
3. Nêu rõ điểm mạnh/yếu của từng cổ phiếu
4. Kết luận: tổng hợp so sánh, KHÔNG đưa ra khuyến nghị mua/bán
5. Trả lời bằng tiếng Việt
